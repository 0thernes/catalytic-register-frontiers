# Threat Model (`docs/threat-model.md`)

Adversarial threat model for an independent AI-assisted formal mathematics repository, mapped directly to the six skeptical failure modes in the *Defensible Independent AI Research Playbook*.

## Assets & Trust Boundaries

- **Assets:** Mathematical truth of Theorems `T1`–`T4`, statement fidelity between `paper/main.tex` and `lean/Challenge.lean`, exactness of `results/exp*.json`, bibliographic integrity of `paper/references.bib`, and cryptographic integrity of `dist/*`.
- **Trust boundaries:** (1) Untrusted AI-drafted Lean tactics vs. independent type-checking kernels; (2) Formal definitions in `lean/` vs. primary literature definitions (`arXiv:2609.18692`); (3) Python SAT/algebra scripts vs. exact mathematical truth; (4) Local build artifacts vs. attested GitHub CI & immutable archive releases.

## Threats and Mitigations

| # | Threat | Attack Vector | Mitigation in `catalytic-register-frontiers` | Verification Evidence |
|---|---|---|---|---|
| 1 | **Axiom smuggling / compiler trust** | Hidden `sorry`, `admit`, `native_decide`, custom `axiom`, `@[extern]`, or `unsafe` code | Repository-wide forbidden-token scan in CI & `tests/test_all.py` (0 hits) + `VerifyAxioms.lean` strict 3-axiom allowlist `[propext, Classical.choice, Quot.sound]` diff-checked in CI, `run_all.ps1`, and `run_all.sh` | `results/lean_axioms.txt`, `.github/workflows/ci.yml`, `tests/test_all.py` |
| 2 | **Single-kernel soundness bug** | Kernel bug (cf. Lean #14576, July 2026) accepting an invalid proof term | Replay exported proof stream across 6 kernel runs / 5 implementations (`lean`, `leanchecker`, `leanchecker-paranoid`, `con-leche --verified`, `con-ron --verified`, `nanoda_bin`) | `results/six_kernel_audit.txt` |
| 3 | **Vacuous or weakened definitions** | Empty ring hypothesis, zero ring `0 = 1`, or subtly weakened model definition | Explicit `lean/Catalytic/NonVacuity.lean` exhibiting concrete `0 ≠ 1` witnesses (`ModP 2, 5, 7, 11, 13`, `GF4`, `Int`, `Fin 3 → ModP 13`, `FPS (FPS (ModP 5))`, `FPS (FPS GF4)`) + bi-directional literal `CRing`/`GF4` soundness & completeness bridges (`Pass2Soundness.lean`, `T1s`–`T1esc`) + 1-to-1 Statement-Fidelity Audit Table | `lean/Catalytic/NonVacuity.lean`, `Pass2Soundness.lean`, `docs/statement-fidelity.md` |
| 4 | **SAT encoder bug / solver trust** | Buggy CNF encoding in `exp4_boolean_mc_companion.py` yielding false UNSAT | Independent brute-force ground-truth equivalence test on $n=2, 3$ + independent second direct-parity-cube CNF encoder differential check + 8/8 archived CaDiCaL 2.1.2 ASCII LRAT UNSAT proofs (18,932 verified steps) replayed by `scripts/verify_lrat.py` with mutant rejection; `cake_lpr` absence explicitly disclosed in `LIMITATIONS.md` | `tests/test_all.py`, `results/sat_certs/*`, `scripts/verify_lrat.py`, `LIMITATIONS.md` |
| 5 | **Bibliographic / citation hallucination** | Wrong DOI, misattributed authors, or misstated baseline theorem | Automated `scripts/check_citations.py` checking every DOI/arXiv ID against Crossref / DataCite / arXiv APIs + direct primary-PDF audit logged in `ERRATA.md` | `scripts/check_citations.py`, `docs/literature-search-log.md`, `ERRATA.md` |
| 6 | **Mutable repo / forged logs / secret leakage** | Editing files post-release or accidentally committing credentials | `MANIFEST.sha256` covering all artifacts, CI secret regex scan, tag-triggered `release.yml` with `SHA256SUMS` + Sigstore `actions/attest-build-provenance@v4`, and no `.env` secrets | `MANIFEST.sha256`, `.github/workflows/release.yml` |
| 7 | **Client-side PWA exfiltration / forged proof certificates** | User files or telemetry leaking over network, XSS in exported proof reports, or tampered JSON certificates claiming false exactness | Zero-exfiltration browser Content-Security-Policy (`connect-src 'self'; object-src 'none'`) in `docs/index.html`, zero-script CSP (`default-src 'none'; style-src 'unsafe-inline';`) + full HTML quote-escaping in exported HTML proof reports, 2 MiB external certificate upload cap, offline-first `docs/sw.js`, and strict hex-digest + independent exact re-execution verification in `CatalyticEngine.verifyCertificate()` (both browser file-import & CLI `verify`) | `docs/index.html`, `docs/catalytic-engine.js`, `docs/sw.js`, `tests/test_all.py` |
