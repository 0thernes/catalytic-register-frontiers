# Per-Component Failure-Mode Analysis (`docs/failure-modes.md`)

> Pipeline artifact `P3.F6`. Identifies how each component of the verification and publication pipeline can fail, how failures are detected, and the exact mitigation in place.

| Component | Failure Mode | Class | Detection Mechanism | Mitigation / Fallback |
|---|---|---|---|---|
| **Lean 4.35 Formalization (`lean/`)** | Statement weakening or vacuous hypothesis bundle while proof type-checks | `error` | `lean/Catalytic/NonVacuity.lean` (`0 ≠ 1` concrete ring/field witnesses) + `docs/statement-fidelity.md` + `lean/Challenge.lean` contract | Every headline theorem is pinned to a short readable `Challenge.lean` statement and instantiated on concrete non-trivial rings. |
| **Lean 4.35 Kernel Soundness** | Single-kernel soundness bug (e.g., Lean bug #14576) or hidden `native_decide`/`axiom` | `bug` | `VerifyAxioms.lean`, forbidden-token scan in `tests/test_all.py`, and replay across 6 checks (`lean`, `leanchecker`, `leanchecker-paranoid`, `con-leche`, `con-ron`, `nanoda_bin`) | Zero `native_decide`, zero custom axioms, multi-kernel verification recorded in `results/six_kernel_audit.txt` and re-run via `lake check --paranoid` on Linux CI. |
| **Windows `lean4lean.exe` Bundled Binary** | Upstream `.olean` header-version mismatch (`incompatible header`) | `problem` | Direct CLI execution test during Pass 2 audit | Documented honestly in `results/six_kernel_audit.txt` and `LIMITATIONS.md`; Linux CI (`lake check --paranoid`) serves as authoritative gate while 5 independent kernel implementations pass on Windows. |
| **CaDiCaL 2.1.2 SAT Companion (`exp4`)** | Encoder bug or unverified UNSAT solver claim | `bug` | Exhaustive $n=2$ + canonical $n=3$ brute-force equivalence test in `tests/test_all.py` + archived `.cnf`/`.lrat` proofs verified by `scripts/verify_lrat.py` (with mutant-killing tests) | No Tier-1 theorem depends on SAT; archived LRAT proofs can also be replayed directly by CakeML's `cake_lpr`. |
| **LaTeX / BibTeX Manuscript (`paper/`)** | Hallucinated DOI, misread preprint metadata, or Tectonic layout overflow | `error` | `scripts/check_citations.py` (live Crossref/DataCite/arXiv verification + retraction check) + 0-warning Tectonic build + visual page inspection | Caught and corrected `BoyarFind2018` DOI, `AFM2025` metadata, and two corollary precision statements (logged in `ERRATA.md` + regression-tested in `tests/test_all.py`). |
| **Windows Bracketed Paths (`Z:\[Vibe Coded (AI)]\...`)** | PowerShell wildcards (`Test-Path`) or Python `glob.glob` misinterpreting `[...]` as character class | `bug` | `AGENTS.md` rule + `tests/test_all.py` + patched `scripts/Audit-Repo.ps1` & `scripts/pipeline-audit.py` | Mandatory `-LiteralPath` in PowerShell, `os.walk` / `glob.escape` in Python, and repo-relative `pytest` invocations. |
| **Provenance Manifest (`MANIFEST.sha256`)** | Untracked caches (`.hypothesis/`) leaking into manifest or global `.gitignore` hiding `.env.example` | `bug` | `test_manifest_and_reuse_hygiene()` in `tests/test_all.py` + `run_all.ps1 -Task audit` | Explicit `.hypothesis/` ignore + `!.env.example` override in `.gitignore`; generator hashes strictly `git ls-files` minus `MANIFEST.sha256` & `provenance/`. |
