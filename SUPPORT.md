# Support

- **Questions & mathematical discussion:** Open a question issue using `.github/ISSUE_TEMPLATE/question.yml` or contact `0_0@0thernes.art`. Check [`docs/faq.md`](docs/faq.md) and [`docs/statement-fidelity.md`](docs/statement-fidelity.md) first.
- **Bugs, mathematical errors, or counterexamples:** Open a finding issue using `.github/ISSUE_TEMPLATE/bug.yml` and tag it with one of the ten finding classes (`bug`, `error`, `issue`, `problem`, `concern`, `dilemma`, `conflict`, `gap`, `hole`, `blindspot`).
- **Independent replications:** Report clean-room replication runs (pass or fail) so they can be logged in [`REPLICATION.md`](REPLICATION.md).
- **Security:** See [`SECURITY.md`](SECURITY.md); never open a public issue for security reports.

Maintenance status: active research artifact, maintained by Alexander S. Donahue (`0thernes`, ORCID `0009-0006-8168-9648`). Responses are best-effort.
